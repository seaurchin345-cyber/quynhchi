## 📌 CÁC NGUYÊN TẮC MẶC ĐỊNH BẮT BUỘC (PERMANENT RULES):

### 1. Nguyên tắc với `index.html`:
- `index.html` là **BẢNG MỤC LỤC DANH SÁCH CÁC DỰ ÁN HTML** (Project Directory).
- **Tuyệt đối KHÔNG sửa đổi giao diện/cấu trúc của `index.html`**.
- Chỉ cập nhật bổ sung tên file vào danh sách khi có file `.html` mới được tạo ra.
- Các liên kết mở file phải luôn mở trong tab mới (`target="_blank"`).

### 2. Nguyên tắc khi người dùng yêu cầu "sửa":
- Nếu người dùng bảo "sửa" mà **không chỉ định rõ tên file cụ thể**:
  - **Bắt buộc phải hỏi lại người dùng** xem muốn sửa file nào.
  - **Tuyệt đối không tự ý đoán hoặc tự ý sửa `index.html`**.
